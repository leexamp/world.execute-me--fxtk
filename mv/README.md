# mv/ — world.execute(me) MV 制作工作区

> **工作模式**：PTC（**P**rompt **T**emplate + **C**ontext）
> **用途**：把一支 MV 交给**另一个专门的 AI** 去做，这里放它需要的全部前置条件。

---

## 怎么用（三步）

1. **开一个新的 AI 会话**（另一个模型/另一个窗口）
2. **把 `PROMPT.md` 里 `═══` 之间的内容整段粘给它**，替换 `【】` 占位符
3. **把这个目录的 `CONTEXT.md` + `STORYBOARD.md` + `HISTORY.md` 一起给它**当上下文包

如果对方 **不能读文件**：把 `CONTEXT.md` 的**第二节（真/假对照表）**和 `HISTORY.md` 整段贴进对话——这是不可省略的最小上下文。

---

## 文件说明

| 文件 | 作用 | 给对方？ |
|---|---|---|
| **`PROMPT.md`** | ★ 提示词模板，直接粘贴 | ✅ 必须 |
| **`CONTEXT.md`** | ★ 前置条件：项目是什么 + **能力边界真/假对照表** + 铁律 + 环境 | ✅ 必须 |
| **`HISTORY.md`** | 真实历史素材库（216 提交，可 checkout 录制的清单） | ✅ 必须 |
| **`STORYBOARD.md`** | 润色版分镜（已修掉 6 处假功能） | ✅ 必须 |
| `record/record_history.sh` | 历史镜头录制辅助脚本 | 可选 |

---

## 这套东西要解决什么问题

原分镜脚本有 **6 处画面在演不存在的功能**（多窗口、Wayland、多点触控、SVG 圆弧、高 DPI 实机效果、去标题栏在 GNOME 下）：

**照拍 = 虚假宣传。**

而 fxtk 这个项目的立身之本恰恰是 **"没实现的不装实现"**（CHANGELOG 里到处是 `[ENV]`/`[N/A]` 诚实标注）。
MV 若违反，就是自己打自己。

**润色后的方向**：把"演不存在的功能"改成 **"演真实的做不到"**——
从减分**变成全片情感高点**，正好接住标题 `[她实现了自己的世界]`：

> **世界是她实现的，你只是那个从头到尾没骗她的工具。**
